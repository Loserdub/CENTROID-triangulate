Core Capabilities
Word2Vec Embedding

Trains a 100-dimensional continuous bag-of-words model locally on your corpus. No pre-trained weights — every run is purpose-built for your data.

CBOW · seed=42 · window=5
KMeans Centroid Discovery

Partitions vocabulary into semantically coherent clusters. The anchor term — the member with highest raw frequency — labels and orients each cluster.

KMeans · k clusters · Euclidean
TF-IDF Signal Ranking

Combines raw count frequency with inverse-document-frequency weighting. A 60/40 composite score surfaces thematically dense, content-rich signals.

score = 0.60 · count + 0.40 · tfidf
Interactive Dashboard

Outputs a single standalone HTML file. Coordinate-mapped SVG cartography, live cluster telemetry, collapsible frequency ledgers, and in-browser ingestion bay.

standalone · no server required
SHA-256 Cache Management

Cryptographic fingerprinting of every input file and parameter set. Unchanged stages are intelligently skipped — reruns on large corpora take seconds, not minutes.

run_state.json · partial resume
Multi-Format Ingestion

Accepts URLs, PDFs (via PyMuPDF), DOCX files, and raw plaintext. Streaming HTTP fetch with 10MB limits, Content-Type validation, and boilerplate scrubbing.

URLs · PDF · DOCX · TXT
Pipeline Architecture
00
State & Checkpoint Manager
Computes SHA-256 hashes of input files and parameter payloads. Queries run_state.json and skips unchanged stages.
01
Web Fetch
Streaming HTTP fetch with Content-Type validation, 10MB size limit, and HTML boilerplate scrubbing.
→ appends to corpus.txt
02
PDF & DOCX Extract
PyMuPDF and python-docx extraction with Unicode punctuation normalization and line unwrapping.
→ appends to corpus.txt
03
Signal / Term Extraction
9-rule scanner: lowercase, min-length, morphology check, EN stopword strip, custom ignore list, TF-IDF computation per source document.
→ word_freq_raw.csv
04
Web Expand (optional)
Rate-limited DuckDuckGo keyword expansion on top-50 terms. Appends semantic context to corpus.
→ appends to corpus.txt
05
Vector Embedding & Clustering
Word2Vec CBOW training, 5-word co-occurrence matrix, KMeans partitioning, Euclidean triangulation, anchor identification.
→ clusters.json · word_freq_ranked.csv
06
Intelligence Report
Lexical gap analysis against target word list. ABSENT / LOW FREQ / PRESENT coverage matrix. Cluster % share and token telemetry.
→ REPORT.md
07
Dashboard Render
Interpolates cluster data and frequency tables into the dashboard template. XSS-safe JSON serialization. Standalone single-file output.
→ dashboard.html
Signal Ranking Formula

A weighted composite score balances high-frequency thematic terms with distinctive, information-dense markers.

Score(w) =
  (0.60 x Raw Count)
  + (0.40 x TF-IDF)
TF-IDF Variant

Smoothed IDF prevents zero-division against small document sets while rewarding rare, content-rich terms across source partitions.

TF-IDF(w,d) =
  TF(w,d) x
  (1.0 + ln((N+1) / (DF(w)+1)))

Pipeline Outputs
outputs/dashboard.html
Standalone single-file browser workbench. SVG cluster cartography, live frequency ledger, co-occurrence heatmap, and gap analysis matrix.
Format: HTML standalone, no server
outputs/REPORT.md
Executive Markdown summary. Cluster telemetry, ranked term tables, lexical gap coverage (ABSENT / LOW FREQ / PRESENT), and runtime metrics.
Format: Markdown
outputs/clusters.json
Raw cluster data payload. Each cluster contains anchor term, member words, centroid distance metrics, density, cohesion, and token share percentage.
Format: JSON
outputs/word_freq_ranked.csv
Full vocabulary ranked by composite score. Includes raw count, TF-IDF per source, combined score, and cluster assignment for every term.
Format: CSV, sortable
outputs/corpus.txt
Normalized, merged corpus from all input sources. Source metadata headers delimit each document partition for transparent provenance tracking.
Format: Plain text, UTF-8
outputs/run_state.json
Checkpoint cache ledger. SHA-256 hashes per stage input, completion timestamps, and per-stage runtime durations for audit and replay.
Format: JSON cache manifest
Quick Start
01 Setup and Install
# clone and navigate
$ git clone https://github.com/you/centroid
$ cd CENTROID
 
# create virtual environment
$ python -m venv .venv
$ .venv\Scripts\activate
 
# install dependencies
$ pip install -r requirements.txt
02 Run the Pipeline
# add your sources
$ echo "https://example.com" >> inputs/urls.txt
$ cp my_doc.pdf inputs/pdfs/
 
# run with defaults
$ python run.py
 
# configure clusters and top-N terms
$ python run.py --top 200 --clusters 10
 
-- open outputs/dashboard.html in browser
